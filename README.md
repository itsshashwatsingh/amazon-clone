
# 🛒 Amazon Front Page Clone (HTML & CSS)

A **static replica** of the Amazon homepage using only **HTML and CSS**. This project is created to practice web layouts, flexbox/grid systems, and responsive design without any JavaScript.

## 🌟 Features

- Amazon-style header with logo, search bar, and cart icon
- Product listing sections and promotional banners
- Fully structured using HTML and styled with CSS
- Responsive layout for various screen sizes

## 🛠️ Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, Media Queries)

## 📚 Purpose

This is a hands-on project to:
- Improve HTML/CSS fundamentals
- Recreate a real-world web design
- Understand layout composition and styling patterns

> ⚠️ **Note:** This is a non-functional frontend clone made for learning purposes only. It does not include real-time features like search, cart, or login.

1. Clone the repository
2. Open `index.html` in your browser
